# Assets Directory

This directory contains assets for Divyansh Gupta's portfolio website.

## Personal Information Config
All paths can be updated in `src/data/portfolioData.ts`:

- `portraitPath`: Default is `/assets/divyansh_portrait.jpg`. Place your portrait image here.
- `resumePath`: Default is `/assets/resume.pdf`. Place your PDF resume here.

If no portrait image is placed here, the website automatically displays a high-tech developer avatar graphic with your initials ("DG") and technical badges!
